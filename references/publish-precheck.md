# 微信公众号发布前审协议

本协议把 [yuwen-cool/yuwen-publish-precheck](https://github.com/yuwen-cool/yuwen-publish-precheck) 的可迁移方法接入本系统。来源仓库面向抖音、小红书和微信视频号；本文件只吸收“候选扫描 + 语义判断 + 保意修复 + 改后复检”的方法，不把来源平台规则写成微信公众号官方规则，也不复制其规则库。

## 预审对象

把下列内容视为一次发布整体，而不是只审正文：

- 文章标题、摘要、开头和正文；
- 图片、封面、截图、图表中的文字与数据；
- 外链、二维码、联系方式、菜单或行动引导；
- 商业合作/推广关系、引用、案例、数据和素材权利；
- 内容证据包中的来源、访问日期、状态和人工决定。

## 两层判断

### 1. 候选扫描

只负责找出需要人工复核的表达，例如绝对化结论、收益/效果保证、无来源数字、虚构身份或案例、商业关系未披露、诱导性行动引导、隐私/版权风险，以及标题—摘要—正文承诺不一致。

### 2. 语义复核

结合上下文、读者、商业属性、行业和证据判断风险。词面命中只是线索，不是最终违规结论；没有命中候选也不能证明文章安全。平台规则、广告要求和敏感行业边界变化时，另行核验当前官方或一手来源。

## 保意修复梯度

按最小损伤顺序处理：

1. **补披露/声明**：说明合作、体验、样本、限制或适用范围。
2. **补证据**：补来源、访问日期、授权、原始记录或把主张降为待验证。
3. **收窄断言**：从普遍结论改为个人观察、特定样本或明确条件下的判断。
4. **最小改写**：尽量保留文章任务、钩子、事实和账号口吻，不用“换几个词”掩盖实质风险。
5. **删除或暂缓**：证据、权利或人工决定仍不足时，保持 `needs-evidence`/`needs-human-decision`，不要硬凑成可发。

禁止把谐音、拼音、拆字、表情、遮挡、图片藏字、分段藏联系方式等当作修复方案。

## 改后复检

修复后重新检查标题、摘要、正文、图片文字、引用、链接、行动引导、商业披露、证据包状态和素材权利。只有复检结果与人工决定都记录后，文章才可以进入唯一 HTML 排版路线；预审不会自动上传、创建草稿或发布。

## 输出合同

```text
预审结论：ready-to-publish | needs-revision | hold

必须改：
- 风险 / 证据 / 具体替换文本

建议改：
- 风险 / 目的 / 可选替换文本

待人工决定：
- 需要确认的来源、授权、商业关系、行业边界或外部动作

改后复检：
- 标题、摘要、正文、图片文字、引用、链接、行动引导：通过 / 仍有问题
- 证据包状态：ready | needs-evidence | needs-human-decision
- 人工决定：approve | revise | hold
```
